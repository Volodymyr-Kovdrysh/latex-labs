## Завдання 4. Створення колонок

```latex

```

Необхідно:

* поділити постер на 2 або 3 колонки;
* у кожній колонці розмістити блоки;
* налаштувати ширину колонок;
* забезпечити рівномірне розміщення інформації.

---

### Приклад:

```latex
\block{Вівторок}{...}

\column{0.33}
\block{Середа}{...}
\end{columns}
```

## Завдання 5. Створення блоків для днів тижня

```latex
\block{Понеділок}{...}
```

Необхідно:

* створити окремі блоки для днів тижня;
* використати не менше 5 блоків;
* у кожному блоці подати розклад на один день;
* вказати час, дисципліну, аудиторію та викладача.

---

### Приклад:

```latex
\hline
Час & Дисципліна & Ауд. & Викладач \\
\hline
08:20--09:40 & LaTeX для науки та освіти & 12 & ПІБ \\
\hline
\end{tabular}
}
```

## Мінімальні технічні вимоги

```latex
\documentclass[a1paper,landscape]{tikzposter}
\usepackage{fontspec}
\usepackage{polyglossia}
\setmainlanguage{ukrainian}
\setotherlanguage{english}
\setmainfont{Times New Roman}
\newfontfamily\cyrillicfont{Times New Roman}
\setmonofont{Courier New}
\newfontfamily\cyrillicfonttt{Courier New}
\usepackage{array}
\usepackage{xcolor}

\usetheme{Basic}

\title{Розклад занять факультету}
\author{Факультет математики та інформатики}

\begin{document}

\maketitle

\begin{columns}

\column{0.33}
\block{Понеділок}{
\begin{tabular}{|c|p{7cm}|c|p{5cm}|}
\hline
Час & Дисципліна & Ауд. & Викладач \\
\hline
08:20--09:40 & LaTeX для науки та освіти & 12 & ПІБ \\
\hline
\end{tabular}
}

\column{0.33}
\block{Вівторок}{
Тут розмістити розклад занять.
}

\column{0.33}
\block{Середа}{
Тут розмістити розклад занять.
}

\end{columns}

\block{Умовні позначення}{
\begin{itemize}
\item Лек. — лекція
\item Лаб. — лабораторна робота
\item Пр. — практичне заняття
\end{itemize}
}

\block{Висновки}{
У ході роботи було створено постер із розкладом факультету засобами класу tikzposter.
}

\end{document}
```
