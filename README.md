# ПРАКТИЧНА ЧАСТИНА

---

## Завдання 1. Вбудовані формули

```latex
\section{Вбудовані формули}
```

Необхідно:

* вставити не менше 5 формул у тексті;
* використати `$...$` або `\(...\)`.

---

### Пояснити:

1. Як вставляється формула в тексті?
2. Коли використовуються вбудовані формули?
3. Чим `$...$` відрізняється від `\(...\)`?
4. Які помилки найчастіше виникають?
5. Як LaTeX відображає математичний режим?

---

## Завдання 2. Виносні формули

```latex
\section{Виносні формули}
```

Необхідно:

* створити формули через `\[...\]`;
* використати `equation`;
* оформити не менше 3 формул;
* хоча б одну формулу пронумерувати.

---

### Пояснити:

1. Різницю між вбудованими і виносними формулами;
2. Коли використовується `equation`;
3. Як працює нумерація;
4. Як вирівнюються формули;
5. Типові помилки.

---

## Завдання 3. Складні математичні вирази

```latex
\section{Складні формули}
```

Необхідно використати:

* `\frac`
* степені та індекси
* `\sqrt`
* грецькі літери
* суму або інтеграл

---

### Пояснити:

1. Як створюється дріб;
2. Як записуються степені;
3. Як вводяться символи;
4. Як працюють великі оператори;
5. Які помилки виникають.

---

## Завдання 4. Посилання на формули

```latex
\section{Посилання на формули}
```

Необхідно:

* додати `\label` до формули;
* створити посилання через `\ref`;
* використати посилання в тексті.

---

### Пояснити:

1. Як працює `\label`;
2. Як створюється посилання;
3. Чому номер не вводиться вручну;
4. Чому потрібна повторна компіляція;
5. Де це використовується.

---

## Завдання 5. Бібліографія через biblatex

```latex
\section{Бібліографія}
```

У преамбулі підключити:

```latex
\usepackage[backend=biber,style=gost-numeric]{biblatex}
\addbibresource{references.bib}
```

---

### Необхідно:

1. Створити файл `references.bib`.
2. Додати **не менше 3 джерел** (книга, стаття, сайт).
3. Використати `\cite{}` у тексті.
4. Вивести список літератури:

```latex
\printbibliography
```

---

### Пояснити:

1. Для чого використовується `biblatex`;
2. Що таке `.bib` файл;
3. Як додається джерело;
4. Як працює `\cite`;
5. Чому використовується `biber`.

---

## Завдання 6. Побудова документа

Документ повинен містити:

✔ формули різних типів
✔ нумеровані формули
✔ посилання на формули
✔ бібліографію
✔ цитування у тексті

---

### У розділі:

```latex
\section{Підсумок роботи}
```

Коротко описати:

1. Які типи формул використано;
2. Чи працюють посилання;
3. Як оформлена бібліографія;
4. Чи виникали помилки компіляції;
5. Що було найскладнішим.

---

## Висновки

```latex
\section*{Висновки}
```

У висновках:

1. Вказати, які інструменти LaTeX було опановано.
2. Описати досвід роботи з формулами.
3. Оцінити роботу з бібліографією.
4. Вказати практичне застосування.
5. Коротко оцінити результат роботи.

---

# Вимоги до оформлення

* Документ компілюється без помилок.
* Формули відображаються коректно.
* Посилання працюють.
* Бібліографія виводиться.
* Використовується `biblatex + biber`.
* Є мінімум 3 джерела.

```latex
\end{equation}

\cite{}
\printbibliography
```
