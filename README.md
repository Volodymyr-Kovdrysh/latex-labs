## Завдання 1. Налаштування параметрів сторінки

```latex
\section{Параметри сторінки}
```

Необхідно:

* підключити пакет `geometry`;
* встановити поля сторінки;
* змінити відступи документа;
* перевірити відображення параметрів у PDF.

---

4. Чому параметри сторінки задають у преамбулі?
5. Які помилки можуть виникати під час налаштування?

---

## Завдання 2. Налаштування стилю заголовків

```latex
\section{Оформлення заголовків}
```

Необхідно:

* змінити вигляд заголовків розділів;
* підключити пакет `titlesec`;
* налаштувати стиль для `\section` або `\subsection`;
* змінити розмір, накреслення або вирівнювання заголовка.

---

### Пояснити:

1. Для чого використовується `titlesec`?
2. Як змінюється стиль заголовка?
3. Які параметри можна налаштувати?
4. Чим стандартне оформлення відрізняється від власного?
5. Які типові помилки трапляються?

---

## Завдання 3. Створення власних команд

```latex
\section{Власні команди}
```

Необхідно:

* створити не менше 3 власних команд через `\newcommand`;
* використати їх у тексті документа;
* хоча б одна команда повинна мати аргумент;
* хоча б одна команда повинна спрощувати набір повторюваних елементів.

---

### Приклади:

```latex
\newcommand{\studentname}{Іваненко Іван}
\newcommand{\term}[1]{\textbf{#1}}
\newcommand{\course}{LaTeX для науки та освіти}
```

---

### Пояснити:

1. Для чого створюються власні команди?
2. Як працює `\newcommand`?
3. Як передаються аргументи в команду?
4. У чому перевага використання макросів?
5. Які помилки найчастіше виникають?

## Завдання 4. Перевизначення команд

```latex
\section{Перевизначення команд}
```

Необхідно:

* використати `\renewcommand`;
* змінити стандартне текстове позначення або поведінку команди;
* показати результат у документі.

---

### Приклад:

```latex
\renewcommand{\contentsname}{Зміст документа}
```

---

### Пояснити:

1. У чому різниця між `\newcommand` і `\renewcommand`?
2. Коли потрібно перевизначати команду?
3. Чому не можна бездумно змінювати стандартні команди?
4. Які ризики має перевизначення?
5. Як перевірити, що команда працює правильно?

---

## Завдання 5. Створення власного середовища

```latex
\section{Власні середовища}
```

Необхідно:

* створити власне середовище через `\newenvironment`;
* використати його в документі;
* оформити блок тексту за допомогою цього середовища.

---

### Приклад:

```latex
\newenvironment{important}
{\begin{center}\bfseries}
{\end{center}}
```

---

### Пояснити:

2. Як працює `\newenvironment`?
3. Із яких частин складається середовище?
4. Чим команда відрізняється від середовища?
5. Де це корисно на практиці?

# Вимоги до оформлення

* Документ компілюється без помилок.
* Параметри сторінки налаштовані коректно.
* Заголовки змінені.

* Усі приклади відображаються коректно.
