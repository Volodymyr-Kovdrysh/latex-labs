# ПРАКТИЧНА ЧАСТИНА

---

## Завдання 1. Форматування тексту

Створити розділ:

```latex
\section{Форматування тексту}
```

Показати:

* два абзаци тексту;
* примусовий перенос рядка;
* виділення тексту:

  * жирний
  * курсив
  * логічне виділення
  * підкреслення
* вирівнювання:

  * по центру
  * по лівому краю
  * по правому краю

---

### Пояснити:

1. Чим абзац відрізняється від переносу рядка?
2. Які команди використовуються для виділення тексту?
3. Які середовища відповідають різним типам вирівнювання?
4. Чому не можна вирівнювати текст пробілами?
5. Який тип форматування є логічним, а який — візуальним?

---

## Завдання 2. Списки

Створити розділ:

```latex
\section{Списки}
```

Необхідно створити:

* маркований список;
* нумерований список;
* вкладений список;
* список із трьома рівнями вкладеності.

---

### Пояснити:

1. Які середовища використовуються для списків?
2. Яка команда створює пункт списку?
3. Чим відрізняється `itemize` від `enumerate`?
4. Як створюється вкладений список?
5. Які помилки найчастіше виникають під час створення списків?

---

## Завдання 3. Таблиці

Створити розділ:

```latex
\section{Таблиці}
```

Необхідно:

* створити таблицю не менше ніж 4×3;
* використати середовище `tabular`;
* задати вирівнювання стовпців;
* додати лінії;
* додати підпис і мітку;
* вставити таблицю у середовище `table`.

---

### Пояснити:

1. Для чого використовується `tabular`?
2. Що означають символи `l`, `c`, `r`?
3. Для чого потрібні символи `&` і `\\`?
4. Навіщо використовувати середовище `table`?
5. Які типові помилки виникають під час створення таблиць?

---

## Завдання 4. Рисунки

Створити розділ:

```latex
\section{Рисунки}
```

Необхідно:

* підключити пакет `graphicx`;
* вставити зображення;
* змінити масштаб;
* використати середовище `figure`;
* додати підпис і мітку.

---

### Пояснити:

1. Для чого потрібен пакет `graphicx`?
2. Що означає параметр ширини зображення?
3. Чому рисунок вставляють через `figure`?
4. Чому рисунки можуть змінювати своє розташування?
5. Які помилки найчастіше виникають під час вставки зображень?

---

## Завдання 5. Перехресні посилання

Створити розділ:

```latex
\section{Перехресні посилання}
```

Необхідно:

* створити посилання на таблицю;
* створити посилання на рисунок;
* створити посилання на розділ;
* використати `\label` і `\ref`;
* виконати повторну компіляцію.

---

### Пояснити:

1. Як працює механізм міток і посилань?
2. Чому номери об’єктів не вводяться вручну?
3. Чому після першої компіляції посилання можуть бути неправильними?
4. У чому перевага автоматичних посилань?
5. Де це особливо важливо?

---

## Завдання 6. Плаваючі об’єкти

Створити розділ:

```latex
\section{Плаваючі об’єкти}
```

Показати:

* таблицю або рисунок із параметрами розміщення (`h`, `t`, `b`, `p`);
* приклад, коли LaTeX змінює позицію об’єкта.

---

### Пояснити:

1. Що таке плаваючий об’єкт?
2. Чому LaTeX може змінювати його позицію?
3. Що означають параметри розміщення?
4. Чому не завжди варто примусово фіксувати позицію?
5. У яких документах контроль позиції є критичним?

---

## ⭐ Завдання 7. Кастомна титульна сторінка

Створити титульну сторінку **без використання `\maketitle`**.

Використати:

* середовище `titlepage`;
* вертикальні відступи (`\vspace`);
* автоматичний розподіл простору (`\vfill`);
* центрування;
* відсутність номера сторінки.

Після титулу перейти на нову сторінку.

---

### Пояснити:

1. Для чого використовується середовище `titlepage`?
2. У чому різниця між `\vspace` і `\vfill`?
3. Як працює вертикальне вирівнювання сторінки?
4. Як прибрати номер сторінки?
5. Чому титульна сторінка зазвичай не нумерується?

---

* ✔ зміст

* ✔ списки

## Висновки

```latex
\section*{Висновки}
```
У висновках підсумувати результати роботи та описати,
які елементи документа було створено і перевірено на практиці.

# Вимоги до оформлення

* Документ компілюється без помилок.
* Є титульна сторінка без номера.
* Зміст відповідає структурі.
* Усі об’єкти мають підписи.
* Посилання працюють коректно.
* Відповіді розгорнуті.
* PDF містить титульну сторінку.
